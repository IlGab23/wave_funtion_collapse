# wave_funtion_collapse
This project is a C# Console project that simulate a tile map generation with the Wave Function Collapse Algorithm using a matrix and letters to simulate tile types

I saw this algorithm on a video on YouTube where it was used to generate a tiled map for a 2D Game and i liked it. 
So i decided to replicate this algorithm with a matrix and letters to simulate tiles.

I did this project because i thought it was fun and because i have no life outside of my room.
